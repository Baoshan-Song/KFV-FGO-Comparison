The contour uses the unweighted range residual norm (m).
Definitions and numerical checks

Trajectories and epoch-wise residuals use online states before later measurements can revise them. Epoch 0 is an initial prior and is not a measurement update. Range norms are unweighted Euclidean norms. The full objective includes prior, motion and the selected robust measurement loss. Its values cannot be compared across different windows or losses. The contour contains only current range measurements, not the full posterior objective. Iteration records use the same stored states as the solver.
